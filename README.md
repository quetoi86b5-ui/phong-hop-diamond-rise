# Phòng họp Diamond Rise

4 phương án cải tạo tường & chiếu sáng, xem 360° và so trước/sau.

[Xem trang Phòng họp Diamond Rise](https://quetoi86b5-ui.github.io/phong-hop-diamond-rise/)

PA 04 có mặt bằng sơ bộ và bốn góc nhìn từ cùng một mô hình. Kích thước phòng 4 × 5 m, cao 2,85 m là giả định từ ảnh hiện trạng.

Dựng lại bằng Python 3.13 với `bpy==5.2.5` và `Pillow`. Lệnh dưới đây xuất mặt bằng, ảnh PNG và mô hình Blender ra thư mục chỉ định.

```sh
python design/render_pa04.py ../pa04-render
```
